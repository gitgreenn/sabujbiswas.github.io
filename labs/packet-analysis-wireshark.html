01 // LAYER-2 PROTOCOL ANALYSIS

ARP Resolution & Poisoning Mechanics

Address Resolution Protocol maps logical IPv4 addresses to physical MAC addresses. Because ARP lacks authentication, an adversary on the local broadcast domain can emit unsolicited (gratuitous) ARP replies to poison switch CAM tables and execute Man-in-the-Middle (MitM) traffic diversion.

Wireshark Display Filter Syntax 
# Filter ARP Broadcast Traffic
arp.opcode == 1  # ARP Requests
arp.opcode == 2  # ARP Replies

# Filter TCP Handshakes with SYN set
tcp.flags.syn == 1 && tcp.flags.ack == 0

# Filter DNS queries for external lookups
dns.flags.response == 0 && udp.port == 53
02 // TLS 1.3 INSPECTION

TLS 1.3 Handshake Dynamics

Compared to legacy TLS 1.2 which required two full round-trips (2-RTT), TLS 1.3 achieves full key exchange in a single round-trip (1-RTT) by sending Diffie-Hellman key shares directly inside the ClientHello packet, encrypting handshake metadata.

Perfect Forward Secrecy

Eliminated static RSA key exchanges; all session keys are generated ephemerally via ECDHE (Elliptic Curve Diffie-Hellman).

Encrypted Server Certificate

In TLS 1.3, the server certificate and extensions are encrypted, obscuring identity details from passive network eavesdroppers.
