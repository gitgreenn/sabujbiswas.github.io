Inter-VLAN Routing & Subnet Hardening

Hands-on simulation isolating Layer-2 broadcast domains across departmental endpoints. Configured IEEE 802.1Q encapsulation on trunk links and created router sub-interfaces to control ingress/egress inter-subnet traversal with Access Control Lists.

Environment Cisco Packet Tracer / GNS3
Hardware Profile Cisco 2901 Router + Catalyst 2960
Key Protocol IEEE 802.1Q (Encapsulation dot1q)
Security Objective Strict VLAN Boundary Isolation
01 // LAB OBJECTIVE & SCENARIO

Problem Scenario

In an unsegmented corporate network, malicious lateral movement, unauthorized sniffing, and ARP poisoning present critical risks. The objective of this lab is to partition physical switches into logical VLANs (Engineering, HR, Management), construct an 802.1Q trunk uplink to a Core Router, and test packet drop policies.

02 // CISCO IOS SWITCH CONFIGURATION

Switch Port Allocation & Trunking

Catalyst-2960-Switch.cfg 
Switch> enable
Switch# configure terminal
! Create VLANs with descriptive names
Switch(config)# vlan 10
Switch(config-vlan)# name Engineering
Switch(config-vlan)# exit

Switch(config)# vlan 20
Switch(config-vlan)# name Guest_Network
Switch(config-vlan)# exit

Switch(config)# vlan 30
Switch(config-vlan)# name Server_Farm
Switch(config-vlan)# exit

! Assign Access Ports to VLAN 10
Switch(config)# interface range FastEthernet0/1 - 10
Switch(config-if-range)# switchport mode access
Switch(config-if-range)# switchport access vlan 10
Switch(config-if-range)# exit

! Configure 802.1Q Trunk Link to Router
Switch(config)# interface GigabitEthernet0/1
Switch(config-if)# switchport mode trunk
Switch(config-if)# switchport trunk allowed vlan 10,20,30,99
Switch(config-if)# no shutdown
Switch(config-if)# exit
