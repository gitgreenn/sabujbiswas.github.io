01 // OBJECTIVE & THREAT MODEL

Perimeter Defense Strategy

Perimeter firewalls serve as the primary defensive barrier separating untrusted public networks from corporate subnets. This lab configures a strict Default Deny posture where only explicitly enumerated services (SSH on port 22 with public keys, HTTPS on port 443) are admitted, while spoofed RFC 1918 addresses from the WAN boundary are silently dropped.

02 // IPTABLES CONFIGURATION

Linux Stateful Firewall Ruleset

Bash // iptables_hardening.sh 
#!/bin/bash
# Reset existing chains and tables
iptables -F
iptables -X
iptables -t nat -F

# Set Default Drop Policy
iptables -P INPUT DROP
iptables -P FORWARD DROP
iptables -P OUTPUT ACCEPT

# 1. Allow Loopback Traffic
iptables -A INPUT -i lo -j ACCEPT
iptables -A OUTPUT -o lo -j ACCEPT

# 2. Allow Established and Related Stateful Connections
iptables -A INPUT -m conntrack --ctstate ESTABLISHED,RELATED -j ACCEPT

# 3. Mitigate SYN Flood Attacks
iptables -A INPUT -p tcp --syn -m limit --limit 20/s --limit-burst 40 -j ACCEPT
iptables -A INPUT -p tcp --syn -j DROP

# 4. Drop Invalid Packets and Port Scan Stealth Flags (NULL, XMAS)
iptables -A INPUT -m conntrack --ctstate INVALID -j DROP
iptables -A INPUT -p tcp --tcp-flags ALL NONE -j DROP
iptables -A INPUT -p tcp --tcp-flags ALL ALL -j DROP

# 5. Permit Dedicated Services (SSH on Port 22, HTTPS on 443)
iptables -A INPUT -p tcp --dport 22 -m conntrack --ctstate NEW -j ACCEPT
iptables -A INPUT -p tcp --dport 443 -m conntrack --ctstate NEW -j ACCEPT

# Save iptables rules persistent
iptables-save > /etc/iptables/rules.v4
