SEC.LAB // 03 STATUS: COMPLETED Linux Administration

Linux Server Hardening & User Privilege Auditing

Systematic operational hardening of Linux servers. Enforced Ed25519 public-key SSH authentication, disabled remote root login, audited SUID/SGID executable binaries, and deployed fail2ban automated rate limiting.

Target OS Ubuntu Server 22.04 LTS / Kali
Authentication SSH Ed25519 Key-Only (No Passwords)
Intrusion Prevention Fail2ban Automated Jails
Audit Scope SUID Executables & Sudoers ACL
01 // SSH HARDENING

SSH Daemon Hardening Configuration

Default OpenSSH configurations frequently permit password-based authentication and root logins, making servers vulnerable to credential stuffing attacks. Below is the hardened /etc/ssh/sshd_config.d/99-hardened.conf:

sshd_config.d/99-hardened.conf 
# Disable Root Login via SSH
PermitRootLogin no

# Enforce Public Key Authentication and Disable Passwords
PubkeyAuthentication yes
PasswordAuthentication no
PermitEmptyPasswords no
AuthenticationMethods publickey

# Cryptographic Ciphers & Key Exchange (Strict Forward Secrecy)
KexAlgorithms curve25519-sha256,curve25519-sha256@libssh.org
Ciphers chacha20-poly1305@openssh.com,aes256-gcm@openssh.com
MACs hmac-sha2-512-etm@openssh.com

# Anti-Brute-Force Connection Constraints
MaxAuthTries 3
MaxSessions 2
ClientAliveInterval 300
ClientAliveCountMax 2
X11Forwarding no
02 // INTRUSION PREVENTION

Fail2ban Jail Defense Implementation

Configured fail2ban to monitor /var/log/auth.log in real time. Any IP failing 3 authentication attempts within a 10-minute window is dynamically injected into an iptables REJECT rule for 24 hours.

/etc/fail2ban/jail.local 
[sshd]
enabled = true
port = ssh
filter = sshd
logpath = /var/log/auth.log
maxretry = 3
findtime = 600
bantime = 86400
banaction = iptables-multiport
03 // PRIVILEGE AUDITING

SUID Binary & Sudoers Auditing

Audited system binaries for dangerous SUID bits (set-user-ID) that permit unprivileged users to execute commands with root permissions (e.g. GTFOBins vectors):

SUID Search & Remediation 
# 1. Search for all files with SUID bit set
find / -perm -4000 -type f 2>/dev/null

# 2. Strip unnecessary SUID permissions from risky utilities
chmod u-s /usr/bin/pkexec
chmod u-s /usr/bin/chfn
chmod u-s /usr/bin/chsh
