SYS.PROJ // 01 Network Infrastructure Perimeter Hardening

Enterprise Inter-VLAN Network Design

Design, topology simulation, and perimeter security implementation of a segmented enterprise network utilizing IEEE 802.1Q Router-on-a-Stick (ROAS), dynamic DHCP pools, and stateful Extended Access Control Lists (ACL-101).

Primary Tool Cisco Packet Tracer / IOS
Protocol Standard IEEE 802.1Q (VLAN Tagging)
Core Architecture Router-on-a-Stick (ROAS)
Security Boundary Extended ACL 101 Filter
01 // TOPOLOGY ARCHITECTURE

Segmented Network Schematic

The core architecture decouples departmental broadcast domains across an enterprise distribution switch. All inter-VLAN routing is performed via a GigabitEthernet 802.1Q trunk link to a Cisco Core Router with dedicated sub-interfaces acting as departmental default gateways.

02 // LOGICAL ADDRESSING

Departmental IP Subnetting Scheme

Each organizational unit is assigned an isolated /24 IPv4 address space. Inter-departmental broadcasts are strictly contained within their respective layer-2 switches, preventing broadcast storms and network congestion.

VLAN ID Department / Function Subnet CIDR Gateway (Sub-interface) DHCP Scope Pool Security Posture
VLAN 10 Engineering & Dev 192.168.10.0/24 192.168.10.1 (g0/0.10) POOL_ENG (10.10 - 10.250) Full Server Farm Access
VLAN 20 Guest / External 192.168.20.0/24 192.168.20.1 (g0/0.20) POOL_GUEST (20.10 - 20.250) BLOCKED from Internal Servers
VLAN 30 Internal Server Farm 192.168.30.0/24 192.168.30.1 (g0/0.30) Static IP Assignments Restricted Ingress via ACL-101
VLAN 99 Management & Native 192.168.99.0/24 192.168.99.1 (g0/0.99) Out-of-band Admin Isolated SVI SSH Only
03 // IMPLEMENTATION

Cisco IOS Configuration Artifacts

Below are the validated configuration scripts deployed to the Cisco 2901 Router and Catalyst 2960 Switch interfaces.

Cisco IOS // Core-Router-ROAS.cfg 
! Bring up primary trunk physical interface without IP
Router(config)# interface GigabitEthernet0/0
Router(config-if)# no ip address
Router(config-if)# no shutdown
Router(config-if)# exit

! VLAN 10 Sub-Interface (Engineering)
Router(config)# interface GigabitEthernet0/0.10
Router(config-subif)# encapsulation dot1Q 10
Router(config-subif)# ip address 192.168.10.1 255.255.255.0
Router(config-subif)# exit

! VLAN 20 Sub-Interface (Guest Network)
Router(config)# interface GigabitEthernet0/0.20
Router(config-subif)# encapsulation dot1Q 20
Router(config-subif)# ip address 192.168.20.1 255.255.255.0
Router(config-subif)# exit

! VLAN 30 Sub-Interface (Production Server Farm)
Router(config)# interface GigabitEthernet0/0.30
Router(config-subif)# encapsulation dot1Q 30
Router(config-subif)# ip address 192.168.30.1 255.255.255.0
Router(config-subif)# exit

! Configure Dynamic DHCP Pools
Router(config)# ip dhcp excluded-address 192.168.10.1 192.168.10.9
Router(config)# ip dhcp pool POOL_ENGINEERING
Router(dhcp-config)# network 192.168.10.0 255.255.255.0
Router(dhcp-config)# default-router 192.168.10.1
Router(dhcp-config)# dns-server 192.168.30.5
Router(dhcp-config)# exit
Cisco IOS // Extended-ACL-101.cfg 
! Define Extended ACL 101 to enforce departmental security boundaries
! Rule 1: Allow Engineering VLAN to reach Server Farm over HTTP/HTTPS/SSH
access-list 101 permit tcp 192.168.10.0 0.0.0.255 192.168.30.0 0.0.0.255 eq 80
access-list 101 permit tcp 192.168.10.0 0.0.0.255 192.168.30.0 0.0.0.255 eq 443
access-list 101 permit tcp 192.168.10.0 0.0.0.255 192.168.30.0 0.0.0.255 eq 22

! Rule 2: Explicitly DROP all traffic from Guest VLAN 20 attempting to reach Server Farm
access-list 101 deny ip 192.168.20.0 0.0.0.255 192.168.30.0 0.0.0.255

! Rule 3: Permit general outbound Internet egress
access-list 101 permit ip any any

! Apply ACL 101 at router sub-interface ingress boundary
interface GigabitEthernet0/0.20
 ip access-group 101 in
04 // DEFENSE-IN-DEPTH

Security Considerations & Hardening

Enterprise networks face significant lateral movement threats if an attacker gains physical or wireless access to access-layer ports. Below are the mitigation mechanisms built into this topology:

VLAN Hopping & Double-Tagging Mitigation

By assigning the Native VLAN to an unused ID (VLAN 99) and disabling Dynamic Trunking Protocol (DTP) across all end-user ports (switchport mode access + switchport nonegotiate), attackers cannot generate double 802.1Q tags to illegally bypass switch encapsulation boundaries.

Layer-2 Broadcast Isolation

ARP broadcasts and NetBIOS traffic generated in Guest VLAN 20 cannot traverse to Engineering hosts, eliminating sniffing attack surfaces.

ACL Boundary Enforcement

Tested packet drops via ICMP echo requests: 100% of packets from 192.168.20.25 to 192.168.30.10 are dropped by Extended ACL 101.

DHCP Rogue Defense

Configured DHCP Snooping on the Catalyst switch; only the uplink trunk to the core router is marked as a trusted DHCP interface.
