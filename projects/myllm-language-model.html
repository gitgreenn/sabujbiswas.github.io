01 // NEURAL TOPOLOGY

Transformer Architecture Schematic

The neural computation graph flows from discrete input token IDs through learned embedding matrices and sinusoidal positional encoders, into multi-layer causal self-attention blocks with LayerNorm and residual bypasses, finally projecting onto linear vocabulary logits.

02 // MATHEMATICAL FOUNDATION

The Mechanics of Causal Self-Attention

Given an input representation matrix X, linear projection weights generate Query (Q), Key (K), and Value (V) tensors. The attention weight distribution is computed by dot-product similarity, scaled by the square root of key dimension d_k to prevent vanishing softmax gradients:

Attention Equation & Causal Mask 
Attention(Q, K, V) = softmax( (Q * K^T) / sqrt(d_k) + M ) * V

Where Mask M is an upper-triangular matrix:
M[i, j] = 0        for i >= j (past and current tokens)
M[i, j] = -infinity for i < j  (future tokens prevented from attending)
03 // CODE IMPLEMENTATION

PyTorch Causal Self-Attention Module

Below is the verified PyTorch module defining causal multi-head self-attention with tensor transposition and causal lower-triangular masking:

PyTorch // attention.py 
import torch
import torch.nn as nn
import torch.nn.functional as F
import math

class CausalSelfAttention(nn.Module):
    def __init__(self, embed_dim=256, num_heads=4, block_size=128, dropout=0.1):
        super().__init__()
        assert embed_dim % num_heads == 0, "embed_dim must be divisible by num_heads"
        self.num_heads = num_heads
        self.head_dim = embed_dim // num_heads

        # Key, Query, Value projections combined into a single matrix for efficiency
        self.c_attn = nn.Linear(embed_dim, 3 * embed_dim)
        self.c_proj = nn.Linear(embed_dim, embed_dim)
        self.dropout = nn.Dropout(dropout)

        # Causal mask register: lower triangular 1s, upper triangular 0s
        self.register_buffer(
            "bias",
            torch.tril(torch.ones(block_size, block_size)).view(1, 1, block_size, block_size)
        )

    def forward(self, x):
        B, T, C = x.size() # Batch, Sequence Length, Embedding Dimension

        # Calculate Query, Key, Value vectors for all heads in batch
        q, k, v = self.c_attn(x).split(C, dim=2)
        k = k.view(B, T, self.num_heads, self.head_dim).transpose(1, 2) # (B, nh, T, hs)
        q = q.view(B, T, self.num_heads, self.head_dim).transpose(1, 2)
        v = v.view(B, T, self.num_heads, self.head_dim).transpose(1, 2)

        # Scaled dot-product attention
        att = (q @ k.transpose(-2, -1)) * (1.0 / math.sqrt(k.size(-1)))
        # Enforce causality: mask out future tokens with -inf
        att = att.masked_fill(self.bias[:, :, :T, :T] == 0, float('-inf'))
        att = F.softmax(att, dim=-1)
        att = self.dropout(att)

        y = att @ v # (B, nh, T, hs)
        y = y.transpose(1, 2).contiguous().view(B, T, C) # Re-assemble head outputs
        return self.c_proj(y)
