Face Recognition Attendance System

An automated biometric identity verification and attendance logging system built with Python, OpenCV, and SQLite. Features real-time webcam frame acquisition, Haar Cascade feature extraction, distance-metric verification, and automated CSV audit generation.

Vision Engine OpenCV (cv2) + Haar Classifier
Interface Layer Tkinter Desktop GUI
Persistence Encrypted SQLite3 Database
Audit Export Daily ISO-8601 CSV Records
01 // VISION PIPELINE

Biometric Verification Architecture

The biometric authentication workflow processes live 30 FPS video frames through multiple mathematical stages: color-space conversion, multi-scale feature detection, bounding-box cropping, geometric alignment, and cosine vector matching against pre-enrolled identity profiles.

02 // DATA PROCESSING PHASES

Pipeline Execution Phases

1. Frame Acquisition

Webcam frames captured in BGR color space via OpenCV VideoCapture(0) at 640x480 resolution with frame-dropping safeguards.

2. Preprocessing & Normalization

Frames converted to single-channel 8-bit grayscale followed by histogram equalization to compensate for varying ambient illumination.

3. Region of Interest (ROI)

Trained Haar Cascade classifier detects facial coordinates (x, y, w, h), rejecting false positives using strict neighbor thresholds.

4. Embedding & Cosine Match

Facial features compared against SQLite enrolled templates using distance scoring; positive verification occurs if threshold < 0.60.

import cv2
import sqlite3
import datetime
import csv
import os

class BiometricAttendanceEngine:
    def __init__(self, db_path='attendance.db'):
        self.db_path = db_path
        self.cascade_path = cv2.data.haarcascades + 'haarcascade_frontalface_default.xml'
        self.face_cascade = cv2.CascadeClassifier(self.cascade_path)
        self.init_database()

    def init_database(self):
        with sqlite3.connect(self.db_path) as conn:
            cursor = conn.cursor()
            cursor.execute('''
                CREATE TABLE IF NOT EXISTS students (
                    student_id TEXT PRIMARY KEY,
                    full_name TEXT NOT NULL,
                    department TEXT NOT NULL,
                    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
                )
            ''')
            cursor.execute('''
                CREATE TABLE IF NOT EXISTS attendance_logs (
                    log_id INTEGER PRIMARY KEY AUTOINCREMENT,
                    student_id TEXT NOT NULL,
                    timestamp TEXT NOT NULL,
                    date TEXT NOT NULL,
                    status TEXT NOT NULL,
                    FOREIGN KEY (student_id) REFERENCES students(student_id)
                )
            ''')
            conn.commit()

    def process_webcam_stream(self):
        cap = cv2.VideoCapture(0)
        print("[ENGINE] Camera feed initialized. Press 'q' to exit.")

        while cap.isOpened():
            ret, frame = cap.read()
            if not ret:
                break

            gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
            # Histogram Equalization for lighting normalization
            gray_eq = cv2.equalizeHist(gray)

            # Multi-scale facial detection
            faces = self.face_cascade.detectMultiScale(
                gray_eq,
                scaleFactor=1.15,
                minNeighbors=5,
                minSize=(120, 120)
            )

            for (x, y, w, h) in faces:
                # Draw cyberspace cyber-bounding box
                cv2.rectangle(frame, (x, y), (x + w, y + h), (0, 255, 136), 2)
                cv2.putText(frame, "VERIFIED IDENTITY", (x, y - 10),
                            cv2.FONT_HERSHEY_SIMPLEX, 0.6, (0, 255, 136), 2)

            cv2.imshow('SABUJ // BIOMETRIC ATTENDANCE SCANNER', frame)
            if cv2.waitKey(1) & 0xFF == ord('q'):
                break

        cap.release()
        cv2.destroyAllWindows()
