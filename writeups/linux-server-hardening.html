Practical Linux Host Hardening & Attack Surface Reduction

Essential security configurations for fresh Linux production servers: key-only SSH authentication, host-based firewalls, brute-force rate limiting, and privilege auditing.

01 // SSH CONFIGURATION

1. SSH Cryptographic Enforcement

Securing access channels is the primary milestone of Linux defense. Enforcing cryptographic keys and disabling password auth eliminates dictionary attacks:

/etc/ssh/sshd_config 
PermitRootLogin no
PasswordAuthentication no
PubkeyAuthentication yes
MaxAuthTries 3
02 // PERIMETER FILTERING

2. Uncomplicated Firewall (UFW) Rules

Default deny all ingress traffic, permit only designated ports:

UFW Commands 
ufw default deny incoming
ufw default allow outgoing
ufw allow 22/tcp
ufw enable
